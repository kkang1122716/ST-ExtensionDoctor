# Extension Doctor (SillyTavern 확장)

설치된 **다른 확장들**이 ST를 느리게 만드는지, 서로 충돌하는지 찾아 주는 진단 도구예요.

- 두 확장이 서로의 변경에 반응하며 끝없이 다시 그리는 **루프**를 자동으로 잡아 알려줘요.
  예: `⚠️ 루프 의심: Prompt Groups ↔ 프롬프트 토글 그룹 (초당 34회)`
- [진단 시작]을 누르면 10~60초 동안 기록해서 **확장별 순위 리포트**를 보여줘요.
  리포트에는 CPU, 감시자 호출 수, 멈춤 구간, 설정 패널 DOM 수, 코드 위험 패턴이 들어가요.
- 리포트를 **AI에게 보내** 원인 설명과 수정안을 받을 수 있어요.
- 동의하면 **임시 보정**을 걸어 당장 버벅임을 줄여요. 다른 확장의 파일은 절대 수정하지 않아요.

ST 1.19.1 기준으로 만들고 시험했어요.

---

## 설치

### 방법 1: ST 화면에서 설치 (권장)
1. ST 상단의 확장(블록 모양) 아이콘 → **Install extension**을 눌러요.
2. 아래 주소를 붙여넣고 설치해요.
   ```
   https://github.com/kkang1122716/ST-ExtensionDoctor
   ```
3. 새로고침해요.

### 방법 2: 폴더 복사
`ST-ExtensionDoctor` 폴더를 통째로 아래 위치에 넣고 새로고침해요.
```
SillyTavern/data/default-user/extensions/ST-ExtensionDoctor/
```
(사용자 이름이 `default-user`가 아니면 그 폴더 이름으로 바꿔요.)

> **가장 먼저 로드돼야 해요.** `manifest.json`의 `loading_order`가 `-1000`으로 되어 있어서
> 다른 확장보다 먼저 시작돼요. 이 값을 바꾸지 마세요.
> 이보다 먼저 로드되는 확장이 만든 감시자는 기록되지 않아요.

## 사용법

확장 설정(블록 아이콘) → **Extension Doctor** 항목을 펼쳐요.

### 진단
- **진단 시작**: 슬라이더로 정한 시간(기본 30초) 동안 기록해요. 평소처럼 ST를 쓰면 돼요.
  진행 중에는 남은 시간이 보이고, **중지**로 언제든 멈출 수 있어요.
- **지금까지 요약**: 새로고침 이후 모은 기록으로 바로 요약해요. 멈춤 구간과 코드 점검은 빠져요.
- **마지막 리포트 보기 / 마지막 AI 결과 보기**: 창을 닫았어도 다시 열 수 있어요. 새로고침하면 사라져요.
- 채팅창에 `/doctor`를 입력해도 진단이 시작돼요.

### 리포트에 나오는 것
| 항목 | 뜻 |
|---|---|
| 루프 / 충돌 | 서로를 다시 부르는 확장 쌍, 같은 영역을 감시하는 확장 쌍 |
| 확장별 순위 | CPU(감시자·타이머·이벤트 콜백 실측 시간), 멈춤 귀속, 감시자 호출 수, 평균, 설정 패널 DOM 수 |
| 많이 불린 감시자 | 어떤 확장이 어떤 요소를 몇 번 감시했는지 + 코드 위치(파일:줄) |
| 멈춤 구간 Top 10 | 화면이 50ms 넘게 멈춘 순간과 그때 실행 중이던 확장 |
| DOM | 확장 설정 패널별 요소 수, 화면 상위 영역별 요소 수, iframe 수 |
| 코드 점검 | 문서 전체 감시, 감시자 안 레이아웃 계산, 100ms 미만 인터벌, 감시 대상 직접 수정 |

[복사(텍스트)]로 리포트를 통째로 복사해서 확장 제작자에게 보낼 수 있어요.

### 임시 보정
루프 경고나 리포트에서 **임시 보정**을 누르면, 무엇을 하는지와 부작용이 적힌 확인 창이 떠요.
동의해야만 적용돼요.

| 보정 | 하는 일 | 부작용 |
|---|---|---|
| **호출 간격 제한** (권장) | 감시자 호출 사이를 최소 200ms 띄워요. 변경이 쉬지 않고 계속 들어오면(루프) 간격을 최대 2초까지 늘려요. | 루프 중에는 화면 갱신이 최대 2초 늦어질 수 있어요 |
| 상대 확장의 변경 무시 | 한쪽이 다른 쪽이 만든 변경에 반응하지 않게 해요. 루프가 완전히 멈춰요. | 상대가 목록을 다시 그린 뒤 이쪽 표시가 어긋날 수 있어요 |
| 감시자 일시정지 | 그 감시자를 아예 끄는 것과 같아요. | 그 확장의 자동 갱신 기능이 멈춰요 |
| 이벤트 건너뛰기 | 특정 확장이 특정 ST 이벤트에 단 핸들러를 실행하지 않아요. | 그 이벤트에 의존하는 기능이 멈춰요 |

- **이번만**: 새로고침하면 풀려요.
- **기억하기**: 다음에 열 때도 적용돼요. ST 설정에 저장돼요.
- 설정 패널의 **적용 중인 보정**에서 하나씩 해제할 수 있어요.

### AI 분석
리포트의 **AI 분석**을 누르면, 보내기 전에 무엇을(확장 이름, 코드 줄 수, 대략 토큰 수) 어디로 보내는지 먼저 보여줘요.
보내는 내용은 아래 두 가지뿐이에요. 전체 파일은 보내지 않아요.
- 리포트 요약
- 문제로 지목된 코드 주변 발췌 (확장당 최대 150줄)

연결 방식은 설정 패널에서 골라요.
1. **현재 채팅 연결**: 지금 채팅에 쓰는 API로 보내요. 그 API 요금이 들어요.
2. **ST 연결 프로필**: 저장해 둔 연결 프로필 중 하나를 골라요. 모델만 바꿔 쓸 수도 있어요.
3. **직접 입력**: OpenAI 호환 주소, 키, 모델을 넣어요. 요청은 ST 서버를 거쳐 보내요(브라우저 CORS 문제 회피).
   - 키는 ST 설정 파일(`settings.json`)에 **저장되지 않아요**.
   - "이 브라우저에 기억"을 체크한 경우에만 이 브라우저(localStorage)에 남아요.
   - `http://`로 접속 중이면 키가 브라우저와 ST 서버 사이를 암호화 없이 지나가요. ST에 다른 API 키를 넣을 때와 같은 조건이에요.

보내기 전 확인 창에서도 **보낼 곳(API)·모델·응답 최대 토큰**을 바로 바꿀 수 있어요. 바꾼 값은 설정 패널에도 저장돼요.
결과 창의 **[다른 API로 다시 분석]** 으로 리포트를 닫지 않고 다시 보낼 수 있어요.

응답은 마크다운으로 보여주고, 코드 블록마다 [복사] 버튼이 붙어요. 응답 HTML은 DOMPurify로 정화해요.

- 응답 최대 토큰 기본값은 16,000이에요. Gemini처럼 "생각하는" 모델은 생각에도 토큰을 써서 답이 중간에 끊기기 쉬워요.
  끊긴 것 같으면 결과 창에 안내가 뜨니 토큰을 늘려 다시 보내세요.
- 수정안은 **다른 사람이 만든 확장의 코드**를 어떻게 바꾸면 좋을지에 대한 제안이에요. Extension Doctor는 다른 확장의 파일을 바꾸지 않아요.
  제작자에게 전달하거나(GitHub 이슈 등), 당장은 [임시 보정]이나 확장 끄기로 대응하세요.
  직접 파일을 고쳐도 그 확장이 업데이트되면 원래대로 덮어써져요.

## 부담(오버헤드) — 실측

ST 1.19.1, Chrome 기준이에요. 1µs = 0.001ms.

| 동작 | 확장 없이 | 확장 켜고 | 차이 |
|---|---|---|---|
| 요소 추가(appendChild) 1회 | 0.89µs | 0.86µs | 측정 오차 수준 |
| 감시자 콜백 전달 1회 | 4.9µs | 6.2µs | +1.3µs |
| setTimeout 1회 (확장 밖에서 호출) | 1.0µs | 8.9µs | +8µs |

- setTimeout은 ST 첫 로드 동안 확장 밖에서 26번 불렸어요. 평소 사용 중 추가 부담은 1초당 1ms보다 훨씬 적어요.
- 루프 감지는 1초에 한 번, 감시자 목록(보통 수십 개)을 훑는 게 전부예요.
- 확장을 **끄면** 이 확장의 코드는 아예 로드되지 않아서 영향이 0이에요.

### 시험 결과 (Prompt Folders + Prompt Groups 동시 사용)
| | 보정 전 | 호출 간격 제한 적용 후 |
|---|---|---|
| 프롬프트 목록 변경 | 초당 494회 | 초당 21회 (−96%) |
| 두 확장 콜백 CPU | 초당 39ms | 초당 2.3ms |

- 두 확장의 화면 요소(그룹 머리줄, 폴더 도구줄)는 그대로 유지됐어요.
- 루프 경고는 페이지를 연 지 몇 초 안에 떴어요.
- 둘 중 하나를 끄면 경고가 뜨지 않았어요.

## 한계
- iframe 안(예: JS-Slash-Runner가 띄우는 창)에서 돌아가는 코드는 계측하지 못해요.
- ST 코어나 이 확장보다 먼저 로드된 코드가 만든 감시자는 기록되지 않아요.
- 확장이 클릭 핸들러나 `await` 뒤에서 바꾼 DOM은 누가 바꿨는지 모를 수 있어요.
  이때는 "알 수 없음"으로 표시되고, 루프 대신 과다 호출 경고만 떠요.
- 멈춤 구간의 확장별 귀속은 Chrome/Edge(long-animation-frame 지원)에서만 돼요.
  다른 브라우저는 "귀속 불가"로 표시돼요.
- 코드 점검은 패턴 기반 추정이라 틀릴 수 있어요. 압축된 파일은 정밀 점검을 못 해요.
- 설정 패널 DOM은 확장이 자기 패널을 붙일 때 기록해요. 놓친 것은 이름으로 추정하고 "(추정)"이라고 표시해요.

## 삭제
확장 관리 화면에서 삭제하거나 폴더를 지우고 새로고침하면 끝이에요.
"기억하기"로 저장한 보정은 ST 설정의 `extensionDoctor` 항목에 남지만, 이 확장이 없으면 아무 일도 하지 않아요.
