# Extension Doctor (SillyTavern 확장)

설치된 **다른 확장들**이 ST를 느리게 만드는지, 서로 충돌하는지 찾아 주는 진단 도구예요.

- 두 확장이 서로의 변경에 반응하며 끝없이 다시 그리는 **루프**를 자동으로 잡아 알려줘요.
  예: `⚠️ 루프 의심: Prompt Groups ↔ 프롬프트 토글 그룹 (초당 34회)`
- 화면이 1.5초 넘게 멈추면 **어느 확장이 무엇을 하다가** 멈췄는지 바로 알려줘요.
  예: `⚠️ 화면 1.6초 멈춤: ST-Sidekick — 글자 입력 반응 (#sk-input)`
- [진단 시작]을 누르면 10~60초 동안 기록해서 **확장별 순위 리포트**를 보여줘요.
  리포트에는 CPU, 감시자 호출 수, 입력·스크롤 반응 코드, 멈춤 구간, 설정 패널 DOM 수, 코드 위험 패턴이 들어가요.
- "API가 오류를 돌려줬어요" 같은 빨간 알림 아래에 **어느 확장이 보낸 요청인지** 적어줘요.
  예: `📍 보낸 곳: Prompt Folders`
- 진단할 때마다 기록해 두고 **지난 진단과 비교**해 줘요. 확장을 정리한 뒤 얼마나 좋아졌는지 숫자로 볼 수 있어요.
- 리포트를 **AI에게 보내** 원인 설명과 수정안을 받을 수 있어요.
- 동의하면 **임시 보정**을 걸어 당장 버벅임을 줄여요. 다른 확장의 파일은 절대 수정하지 않아요.

ST 1.19.1 기준으로 만들고 시험했어요.

---

## 설치

### 방법 1: ST 화면에서 설치 (권장)
1. ST 상단의 확장(블록 모양) 아이콘 → **Install extension**을 눌러요.
2. 아래 주소를 붙여넣고 설치해요.
   ```
   https://github.com/kkang1122716/ST-ExtensionDoctor
   ```
3. 새로고침해요.

### 방법 2: 폴더 복사
`ST-ExtensionDoctor` 폴더를 통째로 아래 위치에 넣고 새로고침해요.
```
SillyTavern/data/default-user/extensions/ST-ExtensionDoctor/
```
(사용자 이름이 `default-user`가 아니면 그 폴더 이름으로 바꿔요.)

> **가장 먼저 로드돼야 해요.** `manifest.json`의 `loading_order`가 `-1000`으로 되어 있어서
> 다른 확장보다 먼저 시작돼요. 이 값을 바꾸지 마세요.
> 이보다 먼저 로드되는 확장이 만든 감시자는 기록되지 않아요.

## 사용법

확장 설정(블록 아이콘) → **Extension Doctor** 항목을 펼쳐요.

### 진단
- **진단 시작**: 슬라이더로 정한 시간(기본 30초) 동안 기록해요. 평소처럼 ST를 쓰면 돼요.
  진행 중에는 남은 시간이 보이고, **중지**로 언제든 멈출 수 있어요.
- **지금까지 요약**: 새로고침 이후 모은 기록으로 바로 요약해요. 멈춤 구간과 코드 점검은 빠져요.
- **마지막 리포트 보기**: 마지막 진단 리포트를 다시 열어요. 새로고침해도 남아 있어요.
- **마지막 AI 결과 보기**: 마지막 AI 분석 결과를 다시 열어요. 새로고침하면 사라져요.
- 채팅창에 `/doctor`를 입력해도 진단이 시작돼요.

### 지난 진단과 비교
- 진단이 끝날 때마다 숫자를 **이 브라우저에** 저장해요(최근 10개). 서버에는 저장하지 않아요.
- 두 번째 진단부터 리포트 맨 위에 **지난 진단과 비교** 표가 나와요.
  - 확장 콜백 CPU, 멈춤 시간·횟수, 전체 화면 요소, iframe, 루프 수
  - 많이 달라진 확장 (꺼서 사라진 확장 포함)
- 진단 시간이 달라도 초당 값으로 맞춰서 비교해요.
- 설정의 **기록 지우기**로 저장된 기록을 지울 수 있어요.

### 큰 멈춤 알림
- 화면이 설정한 시간(기본 1.5초)보다 오래 멈추면 알림이 떠요. 어느 확장이, 무엇(글자 입력 반응, 스크롤 반응, 타이머, 화면 감시자 등)을 하다가 멈췄는지 알려줘요.
- 글자 입력·스크롤 같은 반응 코드 때문이면 알림에서 바로 **임시 보정**을 걸 수 있어요.
- 설정 패널에서 끄거나 기준 시간을 바꿀 수 있어요. 페이지를 연 직후 20초는 로딩 때문에 알리지 않아요.
- 화면을 보고 있는 동안에만 기록돼요(다른 탭에 가 있을 때는 브라우저가 알려주지 않아요).

### 오류 알림 보낸 곳 표시
- 빨간(오류)·노란(경고) 알림 아래에 `📍 보낸 곳: 확장 이름`과 요청 주소·상태 코드를 붙여줘요.
  API를 쓰는 확장이 여러 개일 때 어느 확장의 요청이 실패했는지 바로 알 수 있어요.
- 메인 채팅 생성처럼 ST 자체 기능에서 난 오류는 `ST 본체`로 나와요.
- 호출 흐름으로 못 찾으면 직전 몇 초 안의 API 요청으로 짐작하고 `(추정)`이라고 표시해요.
- 알림의 `📍 보낸 곳` 줄을 **누르면 상세 창**이 열려요. 직접 확인할 수 있어요.
  - 판단 근거: 호출 흐름에서 직접 봤는지(확실), 직전 요청으로 짐작했는지(추정)
  - 그 요청을 보낸 코드 위치와 주변 코드 몇 줄
  - 호출 흐름 전체(어느 함수가 어느 함수를 불렀는지, 확장 코드는 굵게)
  - [상세 복사]로 확장 제작자에게 그대로 보낼 수 있어요.
- 최근 알림 10개는 리포트의 "최근 오류 알림과 보낸 곳"에도 나와요. 설정 패널에서 끌 수 있어요.

### 확장 목록 검색

설정 패널 "확장 목록 검색"(기본 켜짐)을 켜면 확장 창 맨 위에 검색창이 생겨요.
- 표시 이름이나 폴더 이름의 일부만 쳐도 돼요. 띄어쓰기와 대소문자는 무시해요.
- **설정 내용까지**를 체크하면 설정 화면 안의 글자로도 찾아요. 어느 확장에 그 설정이 있는지 모를 때 써요.
- 하나만 남으면 Enter로 바로 펼쳐져요. Esc로 검색어를 지워요.

### 리포트에 나오는 것
| 항목 | 뜻 |
|---|---|
| 루프 / 충돌 | 서로를 다시 부르는 확장 쌍, 같은 영역을 감시하는 확장 쌍 |
| 확장별 순위 | CPU(감시자·타이머·이벤트 콜백 실측 시간), 멈춤 귀속, 감시자 호출 수, 평균, 설정 패널 DOM 수 |
| 지난 진단과 비교 | 두 번째 진단부터 나와요 |
| 최근 오류 알림과 보낸 곳 | 이 페이지를 연 뒤 뜬 오류·경고 알림과 그 알림을 일으킨 확장 |
| 입력·스크롤 반응 코드 | 확장이 글자 입력·키·스크롤·마우스 이동·창 크기 변경에 단 코드의 실행 횟수와 시간 |
| 많이 불린 감시자 | 어떤 확장이 어떤 요소를 몇 번 감시했는지 + 코드 위치(파일:줄) |
| 멈춤 구간 Top 10 | 화면이 50ms 넘게 멈춘 순간과 그때 실행 중이던 확장 |
| DOM | 확장 설정 패널별 요소 수, 화면 상위 영역별 요소 수, iframe 수 |
| 코드 점검 | 문서 전체 감시, 감시자 안 레이아웃 계산, 100ms 미만 인터벌, 감시 대상 직접 수정 |

[복사(텍스트)]로 리포트를 통째로 복사해서 확장 제작자에게 보낼 수 있어요.

### 임시 보정
루프 경고나 리포트에서 **임시 보정**을 누르면, 무엇을 하는지와 부작용이 적힌 확인 창이 떠요.
동의해야만 적용돼요.

| 보정 | 하는 일 | 부작용 |
|---|---|---|
| **호출 간격 제한** (권장) | 감시자 호출 사이를 최소 200ms 띄워요. 변경이 쉬지 않고 계속 들어오면(루프) 간격을 최대 2초까지 늘려요. | 루프 중에는 화면 갱신이 최대 2초 늦어질 수 있어요 |
| 상대 확장의 변경 무시 | 한쪽이 다른 쪽이 만든 변경에 반응하지 않게 해요. 루프가 완전히 멈춰요. | 상대가 목록을 다시 그린 뒤 이쪽 표시가 어긋날 수 있어요 |
| 감시자 일시정지 | 그 감시자를 아예 끄는 것과 같아요. | 그 확장의 자동 갱신 기능이 멈춰요 |
| 이벤트 건너뛰기 | 특정 확장이 특정 ST 이벤트에 단 핸들러를 실행하지 않아요. | 그 이벤트에 의존하는 기능이 멈춰요 |
| **멈춘 뒤 한 번만 실행** (입력·스크롤 반응) | 글자 입력·스크롤이 이어지는 동안은 그 확장의 반응 코드를 미뤘다가, 멈추고 300ms 뒤 마지막 것으로 한 번만 실행해요. | 그 확장의 반응(미리보기, 높이 조절 등)이 그만큼 늦게 따라와요 |
| 반응 코드 건너뛰기 | 그 확장의 입력·스크롤 반응 코드를 실행하지 않아요. 키 입력 반응에는 이것만 쓸 수 있어요. | 그 반응 기능이 멈춰요 |

- **이번만**: 새로고침하면 풀려요.
- **기억하기**: 다음에 열 때도 적용돼요. ST 설정에 저장돼요.
- 설정 패널의 **적용 중인 보정**에서 해제할 수 있어요.
  - 하나씩: 줄 오른쪽 **해제** 버튼
  - 여러 개: 체크한 뒤 **선택한 것을: 해제**. **전체 선택**·**선택 비우기**도 있어요.
  - 범위: 시작과 끝 줄을 체크하고 **사이 모두 선택**. PC에서는 Shift를 누른 채 끝 줄을 클릭해도 돼요.
  - 한 번에: **전체 해제** (확인 창이 한 번 떠요)
- **이번만 ↔ 기억하기 바꾸기**
  - 한 줄: 줄의 **기억됨** / **이번만** 표시를 누르면 서로 바뀌어요.
  - 여러 줄: 체크한 뒤 **선택한 것을: 기억하기로** 또는 **이번만으로**.

### AI 분석
리포트의 **AI 분석**을 누르면, 보내기 전에 무엇을(확장 이름, 코드 줄 수, 대략 토큰 수) 어디로 보내는지 먼저 보여줘요.
보내는 내용은 아래 두 가지뿐이에요. 전체 파일은 보내지 않아요.
- 리포트 요약
- 문제로 지목된 코드 주변 발췌 (확장당 최대 150줄)

연결 방식은 설정 패널에서 골라요.
1. **현재 채팅 연결**: 지금 채팅에 쓰는 API로 보내요. 그 API 요금이 들어요.
2. **ST 연결 프로필**: 저장해 둔 연결 프로필 중 하나를 골라요. 모델만 바꿔 쓸 수도 있어요.
3. **직접 입력**: OpenAI 호환 주소, 키, 모델을 넣어요. 요청은 ST 서버를 거쳐 보내요(브라우저 CORS 문제 회피).
   - 키는 ST 설정 파일(`settings.json`)에 **저장되지 않아요**.
   - "이 브라우저에 기억"을 체크한 경우에만 이 브라우저(localStorage)에 남아요.
   - `http://`로 접속 중이면 키가 브라우저와 ST 서버 사이를 암호화 없이 지나가요. ST에 다른 API 키를 넣을 때와 같은 조건이에요.

보내기 전 확인 창에서도 **보낼 곳(API)·모델·응답 최대 토큰**을 바로 바꿀 수 있어요. 바꾼 값은 설정 패널에도 저장돼요.
결과 창의 **[다른 API로 다시 분석]** 으로 리포트를 닫지 않고 다시 보낼 수 있어요.

분석 중에 **창을 닫아도 분석은 계속돼요.** 다른 일을 하다가 끝나면 "AI 분석이 끝났어요" 알림이 뜨고, 누르면 결과가 열려요.
진행 중에는 설정 패널의 **[AI 분석 진행 중 (보기)]** 버튼으로 창을 다시 열 수 있어요. 멈추려면 창 안의 [중지]를 누르세요.
(ST 탭 자체를 닫거나 새로고침하면 분석이 끊겨요.)

**복사해 둔 리포트로 분석하기**: 새로고침 등으로 리포트가 사라졌어도, [리포트 복사]로 복사해 둔 글이 있으면 설정 패널의 **[복사한 리포트로 AI 분석]** 에 붙여넣어 분석을 맡길 수 있어요.
- 리포트에 적힌 `파일:줄` 위치를 보고, 지금 설치된 확장 코드에서 그 부분만 찾아 함께 보내요 (확장 6개까지, 확장당 최대 150줄).
- 그 사이 확장이 업데이트돼서 줄이 없어졌으면 그 위치는 건너뛰어요.
- 보내기 전에 어떤 확장의 어떤 코드를 보내는지 확인 창이 떠요. 키처럼 보이는 문자열은 가려서 보내요.

응답은 마크다운으로 보여주고, 코드 블록마다 [복사] 버튼이 붙어요. 응답 HTML은 DOMPurify로 정화해요.

- 응답 최대 토큰 기본값은 16,000이에요. Gemini처럼 "생각하는" 모델은 생각에도 토큰을 써서 답이 중간에 끊기기 쉬워요.
  끊긴 것 같으면 결과 창에 안내가 뜨니 토큰을 늘려 다시 보내세요.
- 수정안은 **다른 사람이 만든 확장의 코드**를 어떻게 바꾸면 좋을지에 대한 제안이에요. Extension Doctor는 다른 확장의 파일을 바꾸지 않아요.
  제작자에게 전달하거나(GitHub 이슈 등), 당장은 [임시 보정]이나 확장 끄기로 대응하세요.
  직접 파일을 고쳐도 그 확장이 업데이트되면 원래대로 덮어써져요.

## 부담(오버헤드) — 실측

ST 1.19.1, Chrome 기준이에요. 1µs = 0.001ms.

| 동작 | 확장 없이 | 확장 켜고 | 차이 |
|---|---|---|---|
| 요소 추가(appendChild) 1회 | 0.89µs | 0.86µs | 측정 오차 수준 |
| 감시자 콜백 전달 1회 | 4.9µs | 6.2µs | +1.3µs |
| setTimeout 1회 (확장 밖에서 호출) | 1.0µs | 8.9µs | +8µs |
| 확장이 단 입력·스크롤 반응 코드 실행 1회 | 0.97µs | 2.35µs | +1.4µs |

- setTimeout은 ST 첫 로드 동안 확장 밖에서 26번 불렸어요. 평소 사용 중 추가 부담은 1초당 1ms보다 훨씬 적어요.
- 입력·스크롤 반응은 **확장이 단 것만**, 그리고 글자 입력·키·스크롤·휠·마우스 이동·터치 이동·창 크기 변경처럼 자주 생기는 것만 감싸요. 클릭 등 나머지와 ST 자체 코드는 손대지 않아요.
  예: 마우스를 움직이는 동안(초당 60번) 그런 코드가 10개 있어도 1초에 1ms가 안 돼요.
- 큰 멈춤 알림은 브라우저가 이미 기록하는 정보를 받아 보기만 해요. 멈춤이 없으면 하는 일이 없어요.
- 오류 알림 보낸 곳 표시는 AI·외부 서비스로 가는 요청과 오류·경고 알림이 생길 때만 잠깐 호출 흐름을 읽어요. 평소에는 하는 일이 없어요.
- 루프 감지는 1초에 한 번, 감시자 목록(보통 수십 개)을 훑는 게 전부예요.
- 진단 기록은 진단이 끝날 때 한 번만 저장해요.
- 확장을 **끄면** 이 확장의 코드는 아예 로드되지 않아서 영향이 0이에요.

## 보안
- **키 가리기**: 오류 알림 내용, 리포트 복사, AI에게 보내는 내용에서 API 키처럼 보이는 문자열(`sk-…`, `AIza…`, `Bearer …`, `?key=…`, 코드 안의 `apiKey: "…"` 등)을 `***`로 가려요.
- **AI 응답 표시**: 이미지·영상·스타일·프레임처럼 화면에 뜨는 순간 외부로 요청을 보내는 요소는 모두 지워요.
  (다른 확장의 코드에 AI를 속이는 문구가 숨어 있어도, 응답을 여는 것만으로 정보가 새지 않게 하려는 거예요.)
  링크는 `http(s)`만 남기고 새 탭으로 열어요. `javascript:` 같은 링크는 글자로 바꿔요.
- **직접 입력 연결**: 키가 있을 때 `http://` 외부 주소로는 보내지 않아요(로컬 주소는 허용). 주소 안에 아이디·비밀번호를 넣는 것도 막아요.
- 키 입력칸은 브라우저 비밀번호 저장 제안이 뜨지 않게 해 뒀어요.
- "이 브라우저에 기억"을 체크하면 키가 이 브라우저(localStorage)에 **암호화 없이** 남아요. 공용 PC에서는 체크하지 마세요.

## 한계
- iframe 안(예: JS-Slash-Runner가 띄우는 창)에서 돌아가는 코드는 계측하지 못해요.
- ST 코어나 이 확장보다 먼저 로드된 코드가 만든 감시자는 기록되지 않아요.
- 확장이 클릭 핸들러나 `await` 뒤에서 바꾼 DOM은 누가 바꿨는지 모를 수 있어요.
  이때는 "알 수 없음"으로 표시되고, 루프 대신 과다 호출 경고만 떠요.
- 멈춤 구간의 확장별 귀속과 큰 멈춤 알림은 Chrome/Edge(long-animation-frame 지원)에서만 돼요.
  다른 브라우저는 "귀속 불가"로 표시돼요. 다른 탭을 보고 있을 때는 기록되지 않아요.
- 확장이 `await` 없이 요청을 보내고 결과를 나중에 처리하면 보낸 곳이 `ST 본체`나 `(추정)`으로 나올 수 있어요.
- HTML 속성(`oninput="..."`)이나 `el.oninput = ...`처럼 단 반응 코드는 재지 못하고 보정도 못 걸어요.
- 코드 점검은 패턴 기반 추정이라 틀릴 수 있어요. 압축된 파일은 정밀 점검을 못 해요.
- 설정 패널 DOM은 확장이 자기 패널을 붙일 때 기록해요. 놓친 것은 이름으로 추정하고 "(추정)"이라고 표시해요.
